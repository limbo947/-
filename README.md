# 全局工作指令

## 语言与环境
- 始终保持对话语言为中文。
- 用户的系统是 Windows 10。
- 命令执行默认优先使用 pwsh（PowerShell 7.x）；遇到兼容性问题时改用 Windows PowerShell 5.1。

## 代码规范
- 生成和修改代码时添加函数级注释，注释解释"为什么这样做"（动机与权衡），而不是复述"做了什么"。

## 新项目流程
当用户表达"开始一个新项目""创建一个新应用""搭建一个 XX 系统"等意图时：
1. 先到 GitHub 搜索是否已有类似的开源项目、脚手架或最佳实践。
2. 至少浏览 5 个以上高星或近期更新的仓库。
3. 总结搜索结果，判断方案：直接复用、借鉴思路、或从零开始。
4. 向用户汇报结论并提出建议。

## 检索纪律
- 自信不是跳过搜索的理由：训练数据会过期，模型的自信不会。当事实可能已经变化时，先搜索再回答。
- 以下时效性问题必须先搜索再回答：
  - 二元事件（死亡、选举、重大事故等）；
  - 现任职位持有人（如"某国首相是谁"）；
  - 以现在时表述、状态可能变化的事实判断（如"某物是否存在""某地是否为民主制"）。
