# AI日报仓库

存放每日AI行业动态日报的仓库。

## 目录结构

```
.
├── README.md                      # 本文件
├── 公众号AI日报模板.md             # 公众号版日报模板
├── 小红书AI日报模板.md             # 小红书版日报模板
└── 日报/
    └── 2026.5/                    # 年份.月份
        ├── 5.12/                  # 日期文件夹
        │   └── 示例.md
        └── 5.13/
            └── 5.13.md
```

## 文件存放规则

日报文件按照 **日期规范** 放置：

```
日报/年份.月份/日期/文件名
```

### 命名规则

1. **月份文件夹**：`年份.月份`（如 `2026.5`、`2026.12`）
2. **日期文件夹**：`日期`（如 `5.13`、`12.25`）
3. **日报文件**：文件名和文件类型均不固定，存放在对应日期的文件夹内即可

### 示例

| 日期 | 存放路径 |
|------|----------|
| 2026年5月13日 | `日报/2026.5/5.13/5.13.md` |
| 2026年5月13日 | `日报/2026.5/5.13/AI日报.md` |
| 2026年5月13日 | `日报/2026.5/5.13/日报.docx` |
| 2026年6月1日 | `日报/2026.6/6.1/早报.txt` |

## 模板说明

- **公众号AI日报模板.md**：适用于公众号发布的AI日报格式
- **小红书AI日报模板.md**：适用于小红书发布的AI日报格式

## 使用方式

1. 根据当天日期，在 `日报/` 目录下创建对应的 `年份.月份/日期/` 文件夹
2. 将日报文件放入该文件夹，文件名不限
